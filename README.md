# دار شأن للنشر والتوزيع

سكيلتون Next.js لموقع دار شأن — التصميم والصفحات جاهزة، البيانات ثابتة (mock) لحد ما تُربط بـ Supabase.

## كيف تبلشي بـ Claude Code

1. فكّي ضغط هالمجلد وافتحيه بـ Claude Code
2. قوليلي: **"اقرأ SPEC.md وابدأ بالأولوية رقم ١"** — وبكمل معك من هناك خطوة خطوة
3. أو لخّصيلي وضعك ("عندي حساب Supabase جاهز، بدي نربطه") وبنكمل حسب وضعك

## تشغيل المشروع محلياً

```bash
npm install
cp .env.example .env.local   # ثم عبّي القيم من حساب Supabase
npm run dev
```

افتحي http://localhost:3000

## بنية المجلدات

```
app/
  page.tsx              → الصفحة الرئيسية
  categories/            → تصفح الكتب مع فلاتر
  books/[id]/             → صفحة تفاصيل كتاب
  cart/                   → سلة الشراء
  checkout/               → الدفع
  dashboard/              → لوحة تحكم الزبون
  admin/                  → لوحة تحكم الإدارة
  admin/books/new/        → إضافة كتاب جديد
components/               → مكونات مشتركة (NAV، Footer، بطاقة كتاب، غلاف الكتاب)
lib/                       → عميل Supabase + دوال مساعدة
SPEC.md                    → المواصفات التقنية الكاملة — اقرئيه أول شي
```

كل الأماكن يلي بها بيانات ثابتة أو منطق ناقص معلّمة بتعليق `// TODO` بالكود.
